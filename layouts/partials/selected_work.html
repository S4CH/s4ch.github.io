Black Hat USA 2026. I gave a talk called "When BPF Blinding Goes Dark: Smuggling Raw Gadgets into the Linux Kernel". The kernel is supposed to scramble constants in eBPF programs so attackers can't plant their own bytes in JIT code. I found a case where it didn't. Session · LinkedIn post

Background: eBPF JIT Compiler Internals: Understanding Constant Blinding Implementation. How constant blinding is supposed to scramble those constants before the JIT emits them.

CVE-2026-23417. This is the bug behind the talk. Stores to BPF arena memory skipped the blinding step, so your numbers went straight into kernel code untouched, even with hardening switched on. I found it and wrote the fix. NVD · Patch
